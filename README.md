# 📊 SQL Sales & Customer Analysis

## 📌 Project Overview

This project focuses on analyzing sales and customer data using **SQL and MySQL** to generate meaningful business insights.

The analysis covers customer behavior, revenue, profit, orders, quantity, cities, customer segments and sales trends. The project demonstrates how SQL can be used to transform raw data into useful information for business decision-making.

---

## 🎯 Project Objectives

- Analyze overall sales and revenue performance
- Identify high-value customers
- Analyze customer purchasing behavior
- Compare performance across cities and customer segments
- Analyze revenue and profit patterns
- Identify top-performing customers and products
- Analyze monthly and yearly sales trends
- Apply SQL concepts to real-world business data

---

## 🗂️ Dataset

The project contains two main datasets:

### 1. Ecommerce Sales Data
Contains information related to:
- Order ID
- Order Date
- Customer ID
- Customer Name
- Product
- Quantity
- Gross Sales
- Profit

### 2. Customer Details
Contains customer-related information such as:
- Customer ID
- Customer Name
- City
- Customer Segment

These tables were combined using SQL JOINs for deeper analysis.
